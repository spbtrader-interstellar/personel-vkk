# Персонель · Внутренний контроль

Статичный сайт-справочник внутреннего контроля клиники (только просмотр, без скриптов Google).

- Сайт: https://spbtrader-interstellar.github.io/personel-vkk/
- Календарь сроков: Google Календарь «ВКК Персонель»
- Записи ведутся на бумаге; данные пациентов и личные данные сотрудников здесь не размещаются.

## Светофор из Telegram

- Почепко Л.Ю. или управляющий пишут в группу «Персонель — ВКК» короткую отметку: номер задачи с доски («108 сделали») или узел светофора («холодильник ноябрь ок»).
- Скрипт таблицы каждые 15 минут кладёт сообщения на лист «Входящие».
- Каждое утро, в 07:47 по Екатеринбургу, Claude разбирает новые строки, отмечает задачи на доске и плитки светофора, публикует сайт и отвечает в группу «Принято: …».
- На сайт не попадают телефоны, даты аккредитаций по именам и данные пациентов.

## Доска задач

Задачи 101–155 — сроки из Google Календаря «ВКК Персонель» (номер стоит и в названии события). Номера с 101, чтобы не путать с номерами документов 40–67. Состояние задачи — класс `done` (сделано) или `note` (замечание) у `li.task`; «скоро» и «срок прошёл» считает скрипт на странице по `data-due`.
